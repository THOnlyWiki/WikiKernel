站点信息

显示在浏览器标题栏（「页面名 - 站点名称」）、页眉图标提示、页脚、搜索框占位符、邮件主题与 API 的 sitename 等；留空 = 默认 WikiKernel。

初始账号

邮件发送（可选）

缓存（可选）

页面正文缓存默认关闭；开启后渲染结果按「标题 + 版本号」缓存，页面一改版本号就变，不会返回旧内容。

auto（默认）：配了 Redis 且连得上就用 Redis，否则用进程内缓存。
Redis 连不上会自动退回进程内缓存（页面照常渲染，不报错），日志里留一条警告。

功能开关

按功能分组；一个功能有多个选项时，子配置缩进显示在开关下方（开关关闭后子配置不生效，但设置会保留）。

基础功能
关闭后新用户不能自行注册；管理员 / 行政员仍可在 特殊:注册 创建账号。
内容与编辑器扩展
配置项
启用后 .ts / .tsx 页面的内容在服务端用内置 TypeScript 编译器编译（自包含，不依赖主机装 Node）。
保存 .ts / .tsx 页面后立刻编译，页面顶部直接显示语法诊断（不会阻止保存）。
之后也可以在 特殊:权限配置 → 站点设置 里修改。
