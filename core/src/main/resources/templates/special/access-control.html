在这里配置「谁可以查看 / 编辑 / 创建 / 移动 / 保护 / 删除」页面，保存后立即生效。

匹配优先级：精确标题 > 最长前缀（以 * 结尾，如 帮助:*）> 全部（*）；命中后不再往下匹配。 「指定用户组」为任一即可；「所有人」包含匿名用户；「无人」表示禁止。

也可以在 LocalSettings.yaml 的 wikikernel.permissions.rules 写默认规则：每次启动导入并覆盖同一「目标 + 动作」的网页修改。

对同一「目标 + 动作」再次保存会覆盖旧规则，可用于修改。

站点设置

站点信息
显示在浏览器标题栏（「页面名 - 站点名称」）、页眉图标提示、页脚、搜索框占位符、邮件主题与 API 的 sitename 等；留空 = 默认 WikiKernel。
基础功能
用户本人与管理员始终可以编辑；关闭时其他人点「编辑」只能查看源代码。
关闭后：只有管理员 / 行政员还能打开「特殊:注册」创建账号，其他人访问会提示注册已关闭。
内容与编辑器扩展
启用后 .ts / .tsx 页面的内容会在服务端用内置 TypeScript 编译器编译（自包含，不依赖主机装 Node）。
保存 .ts / .tsx 页面后立刻编译，页面顶部直接显示语法诊断（不会阻止保存）。
超过上限的 .ts / .tsx 源码会被拒绝编译（页面顶部显示诊断）；-1 或 0 表示不限制，留空则用配置文件里的默认值。改完立即生效，不需要重启。
编译器： typescript/5.9.3 · 源码大小上限（KB）： 256 KB
页面正文缓存（Redis 可选）
Redis 连不上会自动退回进程内缓存，不影响使用；配置改完立即生效，不用重启。
