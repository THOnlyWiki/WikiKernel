在这里配置「谁可以查看 / 编辑 / 创建 / 移动 / 保护 / 删除」页面，保存后立即生效。

匹配优先级：精确标题 > 最长前缀（以 * 结尾，如 帮助:*）> 全部（*）；命中后不再往下匹配。 「指定用户组」为任一即可；「所有人」包含匿名用户；「无人」表示禁止。

也可以在 LocalSettings.yaml 的 wikikernel.permissions.rules 写默认规则：每次启动导入并覆盖同一「目标 + 动作」的网页修改。

对同一「目标 + 动作」再次保存会覆盖旧规则，可用于修改。
